I'm a software developer in Bangalore. For the past 18 years I've built software for banks — from backend services to the cloud platforms they run on (containers, Kubernetes, pipelines, and the occasional production fire).

My focus today is building **generative AI applications** — RAG pipelines, agent workflows, and integrating LLMs into real products — alongside **Java / Spring Boot microservices** that power the core systems behind them. I still care deeply about making deployments boring and systems observable (Azure DevOps, GitHub Actions, GoCD, Prometheus, Grafana, ELK), but that’s the platform that supports the product, not the product itself. Day-to-day, most of my code is **Java (Spring Boot)** and **Python**.

Along the way I've mentored a fair number of developers. The two things I keep repeating: read more code than you write, and assume the person who wrote that line before you had a reason.

This blog is where I think out loud — about generative AI, microservices architecture, resilience, and the things that break at scale. If a post here saves you an incident — or a week of yak-shaving an LLM integration — it was worth writing.
