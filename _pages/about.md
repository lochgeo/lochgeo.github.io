I'm a software developer in Bangalore. For the past 18 years I've been building software for banks — lately the cloud side of it: containers, Kubernetes, pipelines, and the occasional production fire.

Most of my day-to-day is CI/CD and observability. I like making deployments boring: automate them end to end with Azure DevOps, GitHub Actions, or GoCD, then watch them closely with Prometheus, Grafana, and the ELK stack so failures are loud and obvious instead of silent. The code is mostly C# and Python.

Along the way I've mentored a fair number of developers. The two things I keep repeating: read more code than you write, and assume the person who wrote that line before you had a reason.

This blog is where I think out loud — about cloud architecture, resilience, and the things that break at scale. If a post here saves you an incident, it was worth writing.
