OpenAI shipped a new frontier pair in GPT-6.2 Astra and Sol, and Cognition launched Devin Bots, which aim past single tasks at owning whole engineering goals. On the writing side: Simon Willison covers two substantial pieces (external sandboxes for coding agents, and the full Datasette server running in a browser), GitHub explains its Agent Host Protocol and argues maintainers need fixes rather than bug reports, and a postmortem-style essay walks through last week's five big outages — none of which, on current evidence, were attacks. The security section covers active exploitation of the Apache Axis RCE against Confluence and N-central, CISA's Java patch-now alert, and the Optimizely script hijack.
