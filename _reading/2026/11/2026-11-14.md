From the engineering blogs, Anthropic published its recommendations for building safety evaluations, Meta got Android's Cuttlefish virtual device framework running natively on Apple Silicon, and GitHub published a practical guide to building agent skills that run on any agent. Beyond AI, PostgreSQL released urgent security updates for all supported versions fixing 52 flaws, Apple's HomeView smart display went on sale, and researchers described new attacks that let a malicious cloud host steal secrets from AMD SEV-SNP confidential VMs.
