Model and tool releases anchored the day: OpenAI introduced GPT-6 Cyber, a cybersecurity model trained to stay within authorized scope; Google's Gemini Omni 1.2 Flash adds native 15-second video generation at 30% lower prices; Mistral launched Studio for building enterprise agents and workflows; and Cognition says its review agent is now cheap enough to run on every pull request. GitHub published the long-awaited deep dive into the Git storage backend it rebuilt for thousands of concurrent agent pushes per repository. On the security side, an emergency OpenSSH release closes an authentication bypass on Alpine/musl systems, GitBook posted a post-mortem of an AI-agent-driven intrusion that forced a full secret rotation, researchers bypassed ChatGPT's Lockdown Mode, Anthropic is declining to fix a remote-command flaw in Claude Dispatch, and Apple confirmed it will scan public iCloud share links for harmful content.
